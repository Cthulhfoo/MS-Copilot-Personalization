# MS-Copilot-Personalization
My MS Copilot Personalization Custom Instructions


In case you aren't familiar...
- Navigate to your account settings (bottom left corner of app at this time)
- Click on the Gear
- Settings from the dialog popup
- Personalization from the Chat Settings menu
- Custom Instructions > Edit Instructions
- You can choose to add one or more of the suggestions, but I've included my preference file for reference
